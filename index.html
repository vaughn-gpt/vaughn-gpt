⚙️ Settings — API key

Your model API key is set on the server, never in this chat and never in browser storage. Set these environment variables where the server runs, then restart it:

LLM_API_KEY — your provider key
LLM_BASE_URL — default https://api.openai.com/v1 (any OpenAI-compatible provider works: OpenAI, Together, Groq, Meta gateways, local Ollama)
LLM_MODEL — default gpt-4o-mini, change to your provider's model name

With no key set, VaughnGPT runs in Demo Mode: live market & quant answers still work; general AI chat waits for the key. This site uses zero Muse tokens — model usage is billed by your own provider, to your own account.
